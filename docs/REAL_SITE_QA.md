# Real Squarespace 7.1 QA Checklist

Run this checklist on controlled Squarespace test sites before production client use.

## Product List
- [ ] Current Products V2 product list detected.
- [ ] 1, 2, 3, 4+ column layouts checked.
- [ ] Sale and sold-out states remain visible.
- [ ] Product links remain clickable.
- [ ] Quick View (if enabled) still works.
- [ ] Long titles/prices do not overflow.
- [ ] Mobile cards stack correctly.

## Product Detail
- [ ] Simple layout checked.
- [ ] Wrap layout checked.
- [ ] Half layout checked.
- [ ] Full layout checked.
- [ ] Variant selectors remain usable.
- [ ] Add to Cart remains usable.
- [ ] Gallery/carousel/lightbox interactions remain usable.
- [ ] Sticky design becomes static on mobile.

## Auto Layout
- [ ] Simple List checked.
- [ ] Carousel checked.
- [ ] Banner Slideshow checked before marking compatible.
- [ ] Team presets checked with/without image/body/button.
- [ ] Testimonial presets checked with long quotes.
- [ ] Native carousel controls and dragging remain usable.

## Summary Block
- [ ] Grid checked.
- [ ] List checked.
- [ ] Carousel checked.
- [ ] Wall checked before marking compatible.
- [ ] Blog content checked.
- [ ] Product content checked.
- [ ] Event content checked.
- [ ] Video content checked.

## Regression
- [ ] Chrome desktop.
- [ ] Safari desktop.
- [ ] Firefox desktop.
- [ ] Edge desktop.
- [ ] iOS Safari.
- [ ] Android Chrome.
- [ ] Keyboard focus visible.
- [ ] Reduced motion honored.
- [ ] No console exceptions.
- [ ] Disable skin restores the native layout.
