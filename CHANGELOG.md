# Changelog

## 0.1.0 — MVP

- Added Squarespace 7.1 structured component detector.
- Added Product List, Product Detail, Summary Block, and Auto Layout adapters.
- Added adapter health checks.
- Added component-specific preset registry.
- Added per-instance scoped CSS classes and design tokens.
- Added Designer Mode overlay with component selection.
- Added Team/Testimonial semantic selection for Auto Layout.
- Added radius, spacing, typography scale, card padding, and image-radius controls.
- Added local draft save, ten-revision local history, and rollback.
- Added native preview and per-component disable.
- Added publish-config export.
- Added MutationObserver re-scan for dynamically rendered content.
- Added reduced-motion support and mobile fallback rules.
- Added installation, architecture, test fixture, and example config.
